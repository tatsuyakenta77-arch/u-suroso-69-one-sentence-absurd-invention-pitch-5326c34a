One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance — midnight snacking:

> The Guilt Fridge dims its light and whispers, "we both know you're not hungry," every time you open it after midnight.

The laugh comes from the invention itself: instead of locking the fridge or counting your calories, it shames you — dimming its light like a disappointed parent and whispering the exact thought you were trying not to have. The fix is silly yet weirdly plausible (a fridge that judges you is one firmware update away), and the mechanism is the whole joke: no lock, no alarm, just guilt, delivered in a whisper at midnight.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single pitch to `/output/entry.txt` and prints exactly that pitch to stdout. No network, no randomness — every run writes the same bytes.
